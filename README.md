# Deadliner-Web

## 前端

- Login框架：Vue
- 主页面框架：Flutter

## 后端

- 后端框架：Node.js
- 数据库：SQLite
- AI部分处理：LiteLLM

[后端使用文档](./backend/README.md)

## Makefile使用指南

- 初始化运行时环境：`make init`
- 安装依赖：`make install`
- 清理：`make clean`
- 推送镜像：`make push`
- 拉取镜像：`make pull`
- 快速提交更改：`make commit MSG="提交信息"`
- 运行：`make run`
